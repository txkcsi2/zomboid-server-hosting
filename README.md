## 自己搭和买面板服，差的是哪几个具体步骤

先说自建这条路的真实样子。一份 2022 年的 Linux 部署留档把流程写得很细，恰好能说明难在哪。

第一步装依赖就走不通的情况很常见。那份留档用的命令是 CentOS 系的 `yum install glibc.i686`、`yum install libstdc++.i686`、`yum install gcc`，注释里写着“可能会缺失环境包，保险起见进入根目录以及安装对应的环境包”。如果你买的是 Ubuntu 镜像，这套 `yum` 命令一条都用不了，得换成 `apt`，还得额外 `adduser steam`、装 `lib32gcc1` 这个 SteamCMD 的 32 位依赖包。系统发行版和教程对不上，是新手第一次放弃的主要原因。

SteamCMD 本身的安装倒是机械活：进 `/usr/local/`，`mkdir steamcmd`，`wget` 下载 `steamcmd_linux.tar.gz`，解压，`cd` 进目录跑 `./steamcmd.sh`。

真正麻烦的在后面。那份留档明确列了两类典型报错：GLIBCXX 版本不匹配、`libstdc++.so.6` 版本过低，解法是“更新或重新编译 GCC”。让一个只是想跟朋友联机的人去重编译 GCC，这事基本就到此为止了。它还提到要开 IPv6 支持、要配 swap 分区应对内存不足。内存不够时靠 swap 顶，代价是读写变慢，服务器卡顿、存档写入延迟都跟着来。

买面板服，这些步骤全部跳过：SteamCMD 装好了，依赖库配好了，端口放行了。你能操作的只剩面板里的文件管理器、配置项和重启按钮。

## B42 的版本问题，比你想象的更要紧

这是很多开服教程讲得最少、但实际最影响体验的一块。

B42 分支下面存在多个小版本。公开内容里至少出现过 B42.12、B42.13、B42.20 三个版本号，其中 B42.20 有“稳定版”的表述。这些版本号之间谁先谁后、具体什么时候发布，资料里没有可靠说明，但它们并存这件事是确定的。

问题出在模组和版本的绑定关系上。模组作者是针对某个具体小版本做的适配，游戏一更新，模组调用的接口变了，就会失效。有模组合集页直接写着“B42.13 合集大半失效！请移步新合集！”，还有合集标注自己是“B42.12 不稳定测试版个人自用”。一个合集整批失效，意味着你花一晚上装好的几十个模组，一次更新之后就全废了。

所以开服时的处理顺序应该是这样：

1. **先定版本，再装模组。** 开服前跟队友确认好统一用哪个小版本，服务端和所有客户端都锁在同一个版本号上。
2. **把模组清单固定下来。** 装哪些模组、各自是哪个版本，列成清单存档。以后要加模组，一次只加一个，加完验证再继续。
3. **服务端不要随手更新。** 面板里有一键更新或者自动更新的选项时，先看清楚它会不会把小版本也一起推上去。

对应的，选服务器时要确认两件在商品页上不一定写清楚的事：服务端版本能不能自己指定、能不能从新版本回滚到旧版本；本地已经调好的模组文件能不能直接上传到服务器的 mods 目录。这两点做不到，前面锁版本的努力就白费了。

## 按人数和玩法选配置

《僵尸毁灭工程》服务端的瓶颈主要在内存，不在核心数。这是由服务端本身的结构决定的：地图区块、僵尸数量、物品状态的维护都吃内存，玩家越多、探索范围越大、模组越多，占用涨得越快。前面那份部署留档把“配置 swap 分区应对内存不足”单独列成一节，也印证了内存是这块最容易出事的地方。

下面这套档位对应是编辑判断，不是官方推荐值，但可以当作起步参考：

- **2 到 4 人、原版或十个以内的模组**：入门档机型，内存 4GB 起。这个规模下服务端跑起来比较轻松，重点是把地图规模控制在合理范围。
- **4 到 8 人、模组二三十个**：5900X 或 Gold 6146 档，内存 8GB 起。模组数量和内存占用基本是线性关系，地图类模组尤其吃内存。
- **十人以上、或者开公开服**：14900KF 档，内存往 16GB 走。公开服的问题是玩家来来去去，每个人探索过的新区域都会留在内存里，跑一整天之后占用比刚开服高出一截。

公开服还要多看一项：带宽。NAT 版的上行带宽不高，几个人玩够用，人数上去之后玩家之间的位置同步会开始延迟。这种情况下独立 IP 版更合适。

一个容易被忽略的成本点是：为了省几十块选了低内存档，跑到一半发现模组装不下，升级又要迁移存档、重新配环境。真要装模组，内存这一档的钱不该省。

## 存档在哪、能不能带走

这件事一定要在付钱之前问清楚，而不是玩了一个月之后才想起来。

需要确认的只有三条：

**存档存在哪。** 面板服一般有文件管理器，能直接浏览服务器目录。开服第一天就进去看一眼，把存档所在的文件夹路径记下来。

**能不能手动备份和下载。** 有些面板只提供整机快照，快照能恢复但拿不出来；有些面板可以直接把存档目录打包下载到本地。后一种更实用，队友之间的进度也能互相留个底。

**换套餐之后数据能不能带走。** 从小配置升到大配置，正常是原地升级、数据保留；但如果要换机型、换机房，或者退掉重买，就需要先下载存档再上传。这个流程能不能走通，取决于上一条。

《僵尸毁灭工程》的多人存档是几个固定目录下的文件，压缩成 zip 上传解压、改一下服务器配置里的存档名称变量、重启服务端就能生效。操作本身不复杂，前提是面板给了你文件管理权限。

## 常见问题

**僵毁服务器到底要多少内存？**

小队伍 4GB 能跑，模组多或者人数上去了建议 8GB 起。判断依据是模组数量和地图规模，不是人数本身。开服后进面板看内存占用曲线，稳定在 70% 以下就没问题；跑到 90% 以上还伴随着卡顿，就该升档了。

**面板服能不能装模组？**

能，前提是面板提供文件上传功能。把创意工坊下载的模组文件夹传到服务端的 mods 目录，再在服务器配置里把模组加进加载列表。有些面板还支持直接填创意工坊 ID 自动拉取，这个要看具体产品。

**B41 和 B42 的服务器能互通吗？**

没有找到权威的互通说明。实操上按“大版本不互通”处理：客户端和服务端的版本必须对得上，B41 的客户端连不上 B42 的服。开服前先把版本号发到群里，让所有人对齐。

**一个人玩要不要开服务器？**

不需要。单人直接本地开局就行，服务器只在多人联机时才有意义。开服务器的价值在于 7×24 在线，队友随时能进，不用等主机上线。

**面板服能改沙盒参数吗？**

能。雨云的面板服教程里就演示了进入游戏目录、找到配置文件、点编辑修改参数的完整流程。沙盒设置里的僵尸数量、物资刷新率、感染速度这些都能改，改完重启服务器生效。

**市面上一二十块的服务器出租能买吗？**

这类商品的配置、使用时长和存档归属通常写得不清楚，有的是共享机器切出来的，有的是按天算的。真要长期玩，选能明确看到配置和计费周期的方案更稳妥。
